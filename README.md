# Protocol Zero

Protocol Zero is an autonomous SRE incident commander prototype for a local Kubernetes microservice environment.

This repository is being bootstrapped from the Windows master plan. Phase 0 establishes the project layout, Python environment contract, and local configuration templates.

## Phase 0 status

- Project skeleton created
- Dependency manifest added
- Environment template added
- Verification scripts scaffolded

## Next steps

2. Create and activate a Python 3.11 virtual environment.

4. Run the verification scripts before starting phase 1.
